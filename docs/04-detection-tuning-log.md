# Detection Tuning Log

A running record of detection-rule changes made **in response to a false
positive** worked in the scenario catalog. When a scenario in
[`14-false-positive/`](../scenarios/14-false-positive/) proves an alert benign and the
fix is to adjust the rule behind it, the change is logged here — so the
tuning is auditable and tied back to the specific scenario that motivated it.

This log is intentionally empty until a false-positive scenario has been
worked and produces a real rule change; no entries are added speculatively.
Each future entry records one rule change, one row:

| Date | Rule ID | Triggering Scenario | Change | Rationale |
